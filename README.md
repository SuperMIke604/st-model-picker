# ST Tools（酒馆增强套件）

一个 SillyTavern 扩展，打包两个功能，各自独立开关：

1. **模型选择器**：把模型下拉框换成「点击弹窗 + 搜索框 + 分组列表」的单选选择器，PC 与移动端通用
2. **聊天文件增强**：「管理聊天文件」弹窗秒开（骨架屏过渡）+ 一键复制聊天文件

## 一、模型选择器

- **可搜索**：按模型名或分组实时过滤（大小写不敏感，同时匹配文本与 value）
- **弹窗式**：基于 SillyTavern 原生 Popup（`<dialog>`），与整体 UI 一致
- **PC / 移动端通用**：不依赖 select2，移动端同样可用
- **键盘友好**：`↑`/`↓` 移动 → `Enter` 选中 → `Esc` 关闭
- **无侵入**：原生 `<select>` 只隐藏不删除，核心的设置读写、`change` 事件、斜杠命令全部照常工作；连接 API 后动态拉取的模型也能搜到（列表每次打开时实时读取）

## 二、聊天文件增强

- **秒开**：核心逻辑是「先请求 `/api/chats/search` 并渲染完所有条目，再显示弹窗」，而该接口在服务端会逐个串行读取每个聊天 jsonl 文件，文件多时要干等。本扩展改为：点击后**立即弹窗 + 骨架屏**，再异步填充列表
- **复制**：每个聊天文件条目的操作区多一个复制按钮
  - 角色聊天：`/api/chats/get` → `/api/chats/save`，新文件名自动去重（`xxx (copy)`、`xxx (copy 2)`…）
  - 群聊：`/api/chats/group/get` → `/api/chats/group/save`，并把新聊天 id 写回群元数据的 `chats` 数组
  - 复制完成后自动刷新列表
- **零核心改动**：只调用官方 API

## 安装

方式一（推荐）：SillyTavern 扩展面板 →「安装扩展」→ 填入本仓库地址。

方式二（手动）：把本目录整个复制到：

```
SillyTavern/public/scripts/extensions/third-party/st-model-picker/
```

刷新页面即可，无需重启。

## 使用

- **模型选择器**：AI 设置面板 → 点击任意模型下拉（右侧带放大镜图标）→ 搜索并选择
- **聊天文件增强**：左下角菜单 →「管理聊天文件」→ 弹窗立即出现；条目操作区点击复制图标即可生成副本

## 设置

扩展面板 → ST Tools：

| 分组 | 选项 | 默认 |
|------|------|------|
| 模型选择器 | 启用弹窗式模型选择器 | 开 |
| 模型选择器 | 移动端也启用 | 开 |
| 模型选择器 | 接管已带搜索的下拉（OpenRouter 等） | 关 |
| 模型选择器 | 接管的模型下拉（按来源启用/禁用） | 全部启用 |
| 聊天文件增强 | 启用聊天文件增强 | 开 |
| 聊天文件增强 | 管理聊天文件弹窗秒开 | 开 |
| 聊天文件增强 | 启用聊天文件复制按钮 | 开 |

## 文件结构

```
index.js         入口：加载设置面板 + 初始化两个功能
settings.js      设置读写（含旧版扁平结构迁移）
utils.js         翻译 / 上下文 / JSON POST 公共工具
model-picker.js  功能一：模型选择器
chat-files.js    功能二：聊天文件增强
style.css        两个功能的样式（.stmp_* / .stcfp_*）
settings.html    扩展面板 UI
```

## 已知边界

- 斜杠命令（如打开管理界面）走核心原生路径，不经过本扩展的秒开拦截
- 群聊复制时若群元数据写入失败，副本文件已生成但不会出现在群聊列表中（文件仍在磁盘，可手动恢复）
- 服务端串行扫描的性能瓶颈仍在（本扩展解决的是「感知等待」）；彻底提速可将 `src/endpoints/chats.js` 中 `/search` 的串行循环改为有并发上限的并行读取
